Privacy policy

School Tracker is a personal tool used only by its owner. It is not available to anyone else.

What it accesses

With the owner's permission, it uses the Gmail API with read-only access (gmail.readonly) to read emails in the owner's own mailbox that match the owner's search rules (for example, emails from their child's school). It cannot send, delete or change any email.

What it does with the data

Matching emails are stored on the owner's own computer and summarised to show dates, reminders and actions on a private dashboard on the owner's home network. Email text is sent to an AI service (Anthropic's Claude) solely to produce those summaries. Data is not sold, shared with anyone else, or used for advertising.

Google user data

School Tracker's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

Access can be revoked at any time at myaccount.google.com/connections, and the owner can delete the stored data from their computer.
